## 🔍 1. ตรวจสอบสิทธิการสมัครรับเลือกตั้ง

### 🎯 จุดเริ่มต้น: Phase A → "คุณสมบัติผู้มีสิทธิสมัคร"

**ขั้นตอน:**
1. ไปที่หน้า `phase-a.html` (หรือคลิก **Phase A — ก่อนเลือกตั้ง** ที่หน้าแรก)
2. ตรวจ **คุณสมบัติ 5 ข้อ** (ม.49 พ.ร.บ.เลือกตั้งท้องถิ่น 2562):
   - สัญชาติไทยโดยการเกิด (ผู้แปลงสัญชาติไม่มีสิทธิ)
   - อายุ **≥ 25 ปี** นับถึงวันเลือกตั้ง (เกิดก่อน/ภายใน 28 มิ.ย. 2544)
   - มีชื่อในทะเบียนบ้าน **กทม. ≥ 1 ปี** นับถึงวันสมัคร
   - จบ **ม.6 / ปวช.** หรือเทียบเท่า (หรือเคยเป็น สส./สว./สมาชิกสภาท้องถิ่น)
   - ไม่เป็นผู้เสียสิทธิเลือกตั้ง (ตรวจที่ [stat.bora.dopa.go.th](https://stat.bora.dopa.go.th))
3. ตรวจ **ลักษณะต้องห้าม 26 ข้อ** (ม.50) — ต้องไม่มีแม้แต่ข้อเดียว

### ⚠️ ถ้าสมัครทั้งที่รู้ว่าขาดคุณสมบัติ
**โทษ ม.120:** จำคุก 1-10 ปี **และ** ปรับ 20,000-200,000 บาท **และ** เพิกถอนสิทธิเลือกตั้ง **20 ปี** (บังคับทั้ง 3) — **ไม่มีทางเลือก**

## 📊 3. Traffy Fondue — ตรวจข้อมูลปัญหารายเขต

### 🎯 ใช้ทำอะไร?
**Traffy Fondue** คือระบบ Crowdsourced complaint data ของกรุงเทพมหานคร — ประชาชนใช้รายงานปัญหาเมือง (ถนนพัง ท่อระบาย ขยะ ไฟส่องสว่าง ฯลฯ) หา**สถิติจริงของเขตคุณ** เพื่อ:
- ทำความเข้าใจปัญหาที่ชาวบ้านในเขตเผชิญจริง
- ใช้เป็น input สำหรับ **"นโยบายหาเสียง"** ที่ตอบโจทย์
- ระบุปัญหาค้างนาน (เวลาแก้ช้า/เร็ว)

### 🖱️ วิธีใช้
1. ที่ **หน้าแรก** (`index.html`) เลื่อนลงไปที่ section **"District Intelligence by LAS"**
2. **เลือกเขต กทม.** จาก dropdown (50 เขต)
3. รอข้อมูลโหลด (**ครั้งแรก ~2 วินาที**; ครั้งต่อไปใน 5 นาที = **ทันที** เพราะมี cache)
4. ดูผลลัพธ์:
   - **Stats cards:** ปัญหาทั้งหมด / แก้แล้ว / กำลังดำเนินการ / รอรับเรื่อง
   - **ช่วงเวลาข้อมูล:** วันที่แรกสุด - ล่าสุดในชุดข้อมูล
   - **แผนที่ Leaflet:** มาร์กเกอร์ตำแหน่งปัญหา (สี = สถานะ)
   - **Fast vs Slow:** ปัญหาที่แก้เร็ว/ช้าที่สุด
   - **ตัวอย่าง 3 เรื่อง (AI Highlight):** พร้อม CTA link ไปดูข้อมูลครบทั้งหมดที่ Traffy Fondue โดยตรง (แผนที่ + สถิติ + ประเภทปัญหาเชิงลึก)

### ⚡ ระบบที่เพิ่มความเร็ว (v2.0 Update)
- **sessionStorage cache 5 นาที** → เปลี่ยนเขตใน 5 นาทีแรก = ไม่ต้อง fetch ใหม่
- **District Index** → lookup O(1) แทน O(N) filter
- **Limit 2000 records** → ครอบคลุมทุกเขตได้ดีขึ้น (เดิม 1000)

### 🔗 ลิงก์
- **Traffy Fondue ของเขตตรง:** (auto-generated ในหน้าเว็บ หลังเลือกเขต)
- **Traffy หลัก:** [bangkok.traffy.in.th](https://bangkok.traffy.in.th)

## 📰 4. ติดตามข่าว กกต. รายวัน (ECT News)

### 🎯 ใช้ทำอะไร?
Widget **"ติดตามข่าว กกต. รายวัน"** บนหน้าแรก — รวบรวม PDF สรุปข่าวรายวันจาก กกต. โดยกรองเฉพาะเนื้อหาที่เกี่ยวกับ **ส.ก. / ผู้ว่า กทม. / เลือกตั้งท้องถิ่น**

### 🔄 Auto-Update (v2.0)
- **Cron update:** รันอัตโนมัติ **3 รอบ/วัน** (07:00, 11:00, 15:00 น. เวลาไทย)
- **Client auto-refresh:** หน้าเว็บ refresh เองทุก **5 นาที** (เงียบๆ ไม่ interrupt user)
- **localStorage cache:** เปิดหน้าเว็บครั้งถัดไป = paint ข่าวเดิมทันที แล้ว fetch ข่าวใหม่ใน background
- **Visibility-change refresh:** กลับมาเปิด tab หลังปิดไว้นาน > 15 นาที = refresh อัตโนมัติ

### 🖱️ วิธีใช้
1. ที่หน้าแรก เลื่อนไปที่ section **"ติดตามข่าว กกต. รายวัน"**
2. ดู **3 ข่าวล่าสุด** พร้อม:
   - Badge **"สำคัญ"** (ถ้าเกี่ยวกับเลือกตั้ง ส.ก. ตรง)
   - Tier badge (**ส.ก. ตรง** / **กว้าง** / **บริบท**)
   - Keyword tags
   - PDF ต้นฉบับของ กกต. (link ตรง)
3. **Click for UPDATE** เพื่อ force refresh ทันที
4. ดูข่าวเต็มที่ [ect.go.th/ect_th/th/dailynews2569](https://www.ect.go.th/ect_th/th/dailynews2569)

## 📋 5. หาเสียง / วันเลือกตั้ง / ปฏิบัติหน้าที่

### Phase B — ระหว่างเลือกตั้ง (หาเสียง)

**DO — สิ่งที่ทำได้ (ม.34, 64, 66, 71, 73):**
- หาเสียงด้วยตนเอง
- แจกเอกสาร / ใบปลิว (ตามขนาด/จำนวนที่ กกต. กำหนด)
- ติดป้ายหาเสียง (ตามสถานที่/ขนาดที่กำหนด)
- หาเสียงทาง Social Media
- แต่งตั้งผู้ช่วยหาเสียง
- **รับการช่วยเหลือจาก สส./สว./ข้าราชการการเมือง** (ม.34 ฉบับ 2/2566 อนุญาตแล้ว)

**DON'T — สิ่งที่ห้ามทำ (ม.65, โทษ ม.126):**
- ❌ ให้ทรัพย์สิน/ประโยชน์ จูงใจ → จำคุก 1-10 ปี **หรือ** ปรับ 20K-200K **หรือ** ทั้งคู่ + เพิกถอน 20 ปี
- ❌ เลี้ยงอาหาร / จัดมหรสพ / ข่มขู่
- ❌ หาเสียงหลัง 18:00 น. วันก่อนเลือกตั้ง (ม.70)
- ❌ ใช้จ่ายเกินวงเงิน กกต. (**ม.127**: จำคุก 1-5 ปี หรือ ปรับ หรือ 3 เท่า + เพิกถอน 10 ปี)

**🚦 ระยะเวลาหาเสียง:**
- **ครบวาระ:** 180 วันก่อนครบวาระ → 18:00 น. วันก่อนวันเลือกตั้ง
- **ยุบสภา:** วันยุบสภา → 18:00 น. วันก่อนวันเลือกตั้ง
