## 📌 เกี่ยวกับเว็บนี้

**ส.ก. Navigator** คือคู่มือครบวงจรสำหรับ **ผู้สมัครสมาชิกสภากรุงเทพมหานคร (ส.ก.)** — ตั้งแต่ก่อนสมัคร → หาเสียง → วันเลือกตั้ง → ปฏิบัติหน้าที่ในสภา กทม. — จัดทำโดยทีมทนายธุรกิจ LAS ร่วมกับ NIA

### 🎯 เนื้อหาครอบคลุม
1. **Phase A** — ก่อนเลือกตั้ง (คุณสมบัติ + ลักษณะต้องห้าม 26 ข้อ + ประกาศ กกต.)
2. **Phase B** — ระหว่างเลือกตั้ง (หาเสียง DO/DON'T + การเงิน + วันเลือกตั้ง)
3. **Phase C** — หลังเลือกตั้ง (ประกาศผล + ยื่นบัญชี + ทรัพย์สิน ป.ป.ช.)
4. **Phase D-E** — ปฏิบัติหน้าที่ (อำนาจหน้าที่ 6 ด้าน + การประชุม + ข้อบัญญัติ + สิทธิประโยชน์)

### 🛡️ คำเตือน
ชุดข้อมูลนี้ **เป็นเพียงการทดลองระบบ AI Legal Research** เท่านั้น ไม่ได้มีวัตถุประสงค์ในการสนับสนุนผู้สมัครรายหนึ่งรายใด โปรดตรวจสอบความถูกต้องของข้อมูลจาก**หน่วยงานราชการที่มีหน้าที่รับผิดชอบโดยตรง**เท่านั้น
